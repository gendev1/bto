BTO Telestrator — no-install demo

This page loads the same capture.js / draw.js / content.js the Chrome extension uses, as plain <script> tags — no install required.

How this works
  1. Start the local inference host: uv run python -m bto.host.server (listens on ws://127.0.0.1:8517/stream, and serves this page at /).
  2. Play the video above. content.js finds it automatically, overlays a transparent canvas, and starts streaming downscaled JPEG frames to the host over WebSocket.
  3. Tactical geometry (formation shape, matchups, offside line, back-pass / press callouts, etc.) streams back and is drawn on the canvas in real time.
  4. Watch the status badge in the corner of the video: connecting → live. It reads overlay off if no reply has arrived for 2s, and DRM protected if the video can't be read from canvas (see SPEC S4.1 — the extension only works on non-DRM sources).
  5. Overlays hide automatically in fullscreen (v1 non-fullscreen scope per SPEC).

Drop your own clip at extension/demo/clip.mp4 (server mounts this directory at /), or point src at any same-origin, non-DRM video.
